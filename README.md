# First Java CRUD

Alper Tunç Ortak – Student ID: 79822

Simple CRUD application built with Spring Boot and Vaadin, based on the Spring guide "Creating CRUD UI with Vaadin".

## Run
./mvnw spring-boot:run
Then open http://localhost:8080

---

## Project Features

This application demonstrates the four fundamental CRUD operations:

| Operation | Description |
|-----------|-------------|
| Create | Add new records to the application |
| Read | View existing records |
| Update | Modify existing records |
| Delete | Remove records |

## Requirements

- Java Development Kit (JDK)
- Git
- A modern web browser

The project includes Maven Wrapper, so installing Maven separately is not required.

## Getting Started

1. Clone the repository from GitHub.
2. Open a terminal in the project directory.
3. Start the application using `./mvnw spring-boot:run`.
4. Wait until the application starts successfully.
5. Open `http://localhost:8080` in your browser.

## Project Structure

- `src/` - Java source code and application resources
- `pom.xml` - Maven project configuration
- `build.gradle` - Gradle build configuration
- `mvnw` - Maven Wrapper for running the application
- `doc/` - Project documentation and screenshots
